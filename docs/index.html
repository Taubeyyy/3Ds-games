3DS Sammlung

Eigene Homebrew-Spiele für den Nintendo 3DS, optimiert für lange Fahrten.

Installation per QR-Code

  1. Auf dem 3DS (mit Custom Firmware) FBI öffnen.
  2. Remote Install → Scan QR Code wählen.
  3. Den QR-Code des Spiels scannen und die Installation bestätigen.
  4. Das Spiel erscheint im HOME-Menü. Spielstände liegen unter sd:/3ds/<spiel>/.
Gebaut mit devkitARM, libctru und citro2d.
